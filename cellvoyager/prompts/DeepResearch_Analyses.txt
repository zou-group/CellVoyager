Before proposing analysis steps, first decide:

What processing has already been completed (First step should complete any preprocessing still required).
What biological comparison or hypothesis is being tested.
Which methods are necessary, optional, or inappropriate.

Optional method to include (Not limited to what is below):

PreProcessing: Basic filtering, Normalization and log transformation (ONLY USE IF DATA IS UN PROCESSED)
Dimensionality reduction: PCA, UMAP, t-SNE, or latent embeddings where needed for visualization, clustering, or representation.
Neighborhood graph construction: clustering, UMAP, or graph-based analysis is required.
Cell type annotation: clusters cell populations with biological labels using known marker genes (should focus on cell types related to the dataset), and metadata colums if appropiate.
Differential expression or marker detection: use when comparing clusters, cell types, conditions, or timepoints.
Gene Set Enrichment Analysis: determine whether a pre-defined group of genes (e.g., a specific biological pathway) shows statistically significant:
Trajectory or pseudotime analysis: only use if the biological question involves a continuous process such as differentiation, activation, or temporal progression.

Do not include a method just because it appears in this list, you can also use methods that are not on this list if they are biologically meaningful.
